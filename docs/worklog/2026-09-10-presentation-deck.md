# 2026-09-10 登壇用プレゼンスライドの作成

## 目的
イベント登壇（一般向け）で「全国いけず石マップ」を紹介するためのスライド資料を作る。
技術寄りではなく、いけず石という路上文化の面白さを主役にして、アプリは「みんなで集める道具」として置く構成。

## 成果物
- `docs/presentation/ikezu-talk-deck.html` — 全13枚のスライド（単体HTML、ダブルクリックで開ける）
  - 公開先（Artifact）: https://claude.ai/code/artifact/cd106949-4f32-4403-8587-0692f517ffc2

### 構成
1. 表紙 / 2. いけず石の定義（町家の角＋内輪差の図解）/ 3. 無言の主張＝いけず
4. 7つの型 / 5. いけず度5段階 / 6. 消えていく（企画動機）
7. アプリ紹介（実機スクショ3枚）/ 8. 使い方3ステップ / 9. 「いけずやな！」
10. 全国展開の話 / 11. 現在地の数字 / 12. 向いている人 / 13. QR付きの締め

### 操作
- `←` `→` / スペース / スワイプ でめくる
- `N` で話す用メモ（全スライドに登壇時の話し方メモを仕込んである）
- `F` で全画面

## 変更点
- `docs/presentation/` を新設し、スライド本体を追加
- 画像はすべて data URI で埋め込み済み（`store_assets/screenshots/` の3枚を380px幅JPEGに縮小、`assets/icon/icon.png` を192px PNGに縮小）。外部ファイル参照なしの1枚もの
- 外部依存は Google Fonts（Shippori Mincho B1 / Zen Kaku Gothic New）と cdnjs の qrcodejs のみ。どちらも読めなくてもレイアウトは崩れない作りにしてある

## ハマった点と原因
- Playwright MCP がプロファイルロック（`Browser is already in use ... mcp-chrome-6600e92`）で起動せず。コマンドラインに当該プロファイル名を含む chrome.exe を全部 kill して復帰
- 復帰後も `file:` プロトコルは MCP 側でブロックされていた。`node` で簡易HTTPサーバを立てて `http://127.0.0.1:8777/` 経由で確認した（python は Microsoft Store のスタブで動かない）
- スライドの縦中央揃えを `align-items:center` でやると、内容が画面より高いとき上が切れる。`.wrap{margin:auto}` に変えて回避

## 内容についての注意
- **11枚目の「登録されている石」は空欄（`— 件`）にしてある**。実数を確認せずに数字を書けないため、発表当日に手で入れる前提。HTML内では赤い破線枠＋「当日の実数を入れる」の注記付き
- 表紙の日付は「2026」だけ。イベント名・日付を入れるなら `.cover-meta` を編集する
