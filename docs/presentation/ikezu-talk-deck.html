つかみ。「みなさん、京都の道歩いてて、家の角にゴロッと石が置いてあるの見たことないですか？」と会場に投げかけてから次へ。自己紹介は短く、10秒で。

定義

家の角に、
石が置いたある。

道が狭い京都の町では、車が曲がりきれずに家の角を削っていく。それを防ぐために、角へ石を据える。これが「いけず石」です。

古いものは江戸期からとも言われ、町家の並ぶ路地にはいまも当たり前のように残っています。

町家の角 角を切って曲がる車 いけず石

図は平面図。「内輪差で角を削られる」→「石で物理的に止める」という実用の説明にとどめる。ここでは、まだ"いけず"の話はしない。次のスライドでひっくり返すため。

この石の、ほんまの話

「うちの角、削らんといてな」
——とは、誰も言うてへん。

石は一言もしゃべりません。看板も貼り紙もない。ただ置いてあるだけで「これ以上寄るな」が伝わる。

はっきり言わずに、察させる。この間合いこそが京都で言う「いけず」。だから、いけず石。

実用品でありながら、無言の主張。
だから一つとして同じ石がない。

ここが一番のヤマ。間を取ってゆっくり読む。笑いが起きたら受けてから次へ。「持ち主の性格が石に出る」という言い方をすると、次の分類スライドにつながる。

分類

石にも、流派がある。

其の一埋め込み型地面に半分埋めて固定。動かされへん本気の構え。
其の二置き石型ただ置いてあるだけ。いちばんよう見かける。
其の三連続型何個も並べて壁に。ここから先は通さん、の意思。
其の四大型石とにかくデカい。存在感だけで語ってくる。
其の五装飾型灯籠や飾り石。美しさで距離を取らせる上級者。
其の六複合型埋めて、並べて、飾って。合わせ技の総合芸術。
其の七その他石臼、車止め、謎の物体。分類しきれん個性派。
自由自分で足せるええ呼び名を思いついたら、その場で新しい型を作れます。

これはアプリの実際のカテゴリー。1つの石に最大3つまで付けられる。「石臼を転用したいけず石」の実物写真が後のスライドに出るので、"その他"のところで軽く予告してもいい。

主観の指標

いけず度、
五段階。

石の大きさでも古さでもなく、「どんだけ寄せつけへんか」を見た人の主観で付けます。

正解はありません。人によってズレるのが、いちばんおもろいところ。

ちょっと置いてみた

はっきり「寄るな」
いけず度 3
歩行者にも圧
いけず度 4

段階の名前は自分で付けたもの。会場の写真を1枚見せて「これ何点？」と聞くと盛り上がる。手が挙がるようなら簡単に多数決を取る。

課題

そして、静かに消えていく。

道路の拡幅、建て替え、駐車場化。気づいたら無くなっている。いけず石は文化財でも登録物件でもないので、消えても記録が残りません。

「あの角の、あの石」を証明できるものが、どこにもない。

残っている今のうちに、位置と写真を残しておきたい。

アプリには「現存する／現存しない」のフラグがある。無くなった石も削除せず"消えた記録"として残す設計にしている、という話をここでする。企画の動機そのもの。

つくったもの

全国いけず石マップ

実機を持っていれば、ここでスマホ画面を出して現物を見せるのがいちばん強い。詳細画面に出ているのは吹田で見つけた「石臼いけず石」。石臼を転用した実例として説明できる。

使い方

やることは、三つだけ。

一 見つける

散歩の途中で「お、置いたある」と気づく。それが全部のはじまり。

二 撮る

その場で撮影するか、あとからアルバムを選ぶ。1件につき5枚まで。

三 置く

地図をタップして場所を指定。型といけず度を付けたら登録完了。

早ければ、立ち止まってから一分。

「めんどくさそう」と思わせないのがこのスライドの役目。実際に登録の流れをその場でやってみせると効く。位置は地図をドラッグして微調整できることも触れる。

ひとりで集めへん

で分かち合う。

いいねボタンの名前は「いけずやな！」。ええ石を見つけた人に、ちゃんと拍手が届くようにしています。

反応
いけずやな！ と コメント

「これは5点やろ」「近所にもあります」みたいなやりとりが、石ごとに残ります。

名前
ニックネームで投稿

本名は要りません。誰が見つけた石か、だけが残ります。

発見
近い順・型で絞り込み

旅先で開けば、その街の石が近い順に出てきます。

「いけずやな！」は関西弁のいいね。ここは笑いどころなので、ボタン名だけ言って一拍置く。データはみんなで共有していて、誰かが登録した石は全員に見える。

ここが本題

京都だけの
話やない。

狭い道と古い家がある街には、たいがい似た石があります。名前が付いてへんだけ。

大阪にも、奈良にも、東京の下町にも。「全国」いけず石マップという名前は、そこに賭けています。
